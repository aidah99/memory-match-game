# memory-match-game
A simple Memory Card Game built with HTML, CSS and JavaScript.

## Features

- 16 memory cards
- Random card shuffling
- Match pairs of cards
- Restart button
- Win message

## Technologies

- HTML
- CSS
- JavaScript

## How to Play

1. Click on a card to reveal it.
2. Click another card.
3. Try to find matching pairs.
4. Match all the cards to win!
